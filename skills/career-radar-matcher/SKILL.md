# Career Radar Evidence-Grounded Matcher (Approach A / BYOA)

Matches newly scanned official ATS jobs against the candidate's local evidence files without calling external paid LLM APIs, then passes drafts through `career-radar apply-match` to check IDs, some numeric tokens, and required structure. Review every claim: the validator cannot establish semantic support or truth.

## Workflow

1. **Inspect Today's Digest**:
   - Read `output/scan/scan_digest.json` (generated by `career-radar scan`).
   - Review `matched_new_or_updated` items and any full JD text inside `output/scan/jobs/*.md`.

2. **Load Ground-Truth Candidate Evidence**:
   - Read the user's private `workspace/master_profile.md` and `workspace/project_library.md` (or the user-specified external career SSOT directory).
   - Never fabricate metrics, employer scopes, or project IDs. Omit private-only constraints from external `recruiter_brief` text.

3. **Draft Structured Match JSON**:
   Write a JSON object per job matching this exact schema:

   ```json
   {
     "company": "Nova Robotics",
     "external_id": "SR-1001",
     "title": "Operations Data Analyst",
     "location": "Guangzhou, China",
     "url": "https://careers.example.com/nova/SR-1001",
     "fit_level": "high",
     "matched_evidence": [
       {
         "evidence_id": "P1",
         "level": "self_reported",
         "claim": "Prepared inventory reports using SQL (P1)."
       },
       {
         "evidence_id": "P3",
         "level": "verified",
         "claim": "Built a Python demand forecasting demo from synthetic data (P3)."
       }
     ],
     "gaps": [
       "Production forecasting experience has not been demonstrated."
     ],
     "questions_to_ask": [
       "Which inventory and delivery systems does the team use?"
     ],
     "recruiter_brief": {
       "role": "Operations Data Analyst",
       "company": "Nova Robotics",
       "fit_summary": "SQL and inventory reporting.",
       "evidence_points": [
         "P1: SQL reporting",
         "P3: Python forecasting demo"
       ],
       "location_availability": "Guangzhou / full-time",
       "open_gaps": "No production forecasting experience claimed."
     }
   }
   ```

4. **Validate and Render via `apply-match`**:
   Run:

   ```bash
   PYTHONPATH=src python3 -m career_radar apply-match \
     --match-json /tmp/match-SR-1001.json \
     --profile workspace/master_profile.md \
     --projects workspace/project_library.md \
     --out output/scan/jobs/nova-robotics-sr-1001.md
   ```

   - If the command exits with code `2`, inspect the reported `ValidationIssue` entries (`UNKNOWN_EVIDENCE_ID`, `INVALID_EVIDENCE_LEVEL`, `UNGROUNDED_NUMERIC_CLAIM`, `INVALID_RECRUITER_BRIEF`), fix the JSON strictly from real source facts, and re-run until exit code `0`.
